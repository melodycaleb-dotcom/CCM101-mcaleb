# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory is my first Cloud Computing onboarding activity. I used the KillerCoda Playground to work with a Linux environment and practiced basic tasks that are commonly used by cloud engineers.

## Objectives

* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Create and organize files and directories.
* Create a professional GitHub repository.
* Document technical work using Markdown.

## Activities Performed

During this laboratory, I:

1. Accessed an Ubuntu Linux environment using KillerCoda.
2. Created a new Linux user named `mcaleb`.
3. Set a password and logged in to the new user account.
4. Checked my current username, working directory, and hostname.
5. Identified the Linux distribution, kernel version, CPU, memory, and disk space.
6. Created a Cloud Computing workspace with different folders.
7. Created and edited Markdown files.
8. Created my Cloud Computing portfolio on GitHub.
9. Organized screenshots and laboratory documentation.

## Linux Commands Used

| Command               | Purpose                              |
| --------------------- | ------------------------------------ |
| `whoami`              | Shows the current username           |
| `pwd`                 | Shows the current working directory  |
| `hostname`            | Shows the system hostname            |
| `cat /etc/os-release` | Shows Linux distribution information |
| `uname -r`            | Shows the kernel version             |
| `lscpu`               | Shows CPU information                |
| `free -h`             | Shows memory information             |
| `df -h /`             | Shows available disk space           |
| `mkdir`               | Creates directories                  |
| `cd`                  | Changes directories                  |
| `ls`                  | Lists files and directories          |
| `cat`                 | Displays file contents               |
| `nano`                | Creates and edits text files         |
| `useradd`             | Creates a new Linux user             |
| `passwd`              | Sets or changes a user's password    |
| `su`                  | Switches to another user             |

## Skills Learned

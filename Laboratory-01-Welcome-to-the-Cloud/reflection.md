# Reflection

This laboratory activity gave me a better understanding of how cloud engineers work with Linux environments. As a 4th-year Information Technology student, I have already encountered different technologies, but this activity helped me practice using the Linux terminal and understand its role in cloud computing.

I learned how to create a Linux user, navigate directories, check system information, and organize files using commands. I also learned how to create Markdown files and organize my work in a GitHub repository.

At first, using the terminal felt a little unfamiliar, but following each step helped me become more comfortable with Linux commands. Overall, this activity was a good starting point for improving my cloud computing and system administration skills.
